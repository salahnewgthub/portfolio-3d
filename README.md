# Salahuddin Muhammad — 3D Web & AI Portfolio

Welcome to the official source code for my professional portfolio. This project represents the intersection of my expertise as an educator, 3D web developer, and AI enthusiast.

## Project Overview

This portfolio is an immersive, interactive digital experience built to showcase my professional identity, technical projects, and learning journey in Agentic AI and 3D web development.

### Key Features
- **Cinematic Hero Section:** Immersive 3D scene built with React Three Fiber.
- **GSAP Animations:** Smooth, cinematic storytelling and scroll-triggered animations.
- **Professional Sections:** Detailed About, Skills, and Featured Projects sections.
- **Interactive Contact Form:** Functional contact experience.
- **Responsive Design:** Fully optimized for desktop, tablet, and mobile.

## Technologies Used

- **Framework:** React.js + Vite
- **3D Graphics:** Three.js + React Three Fiber + @react-three/drei
- **Animations:** GSAP + ScrollTrigger
- **Styling:** CSS3
- **Icons:** Lucide React
- **Deployment:** Vercel

## Development Commands

### Prerequisites
- Node.js (v18+ recommended)
- npm

```bash

```

### Development
```bash
npm run dev
```

### Production Build
```bash

```

## Project Structure
- `src/components/`: Modular React components for different sections.
- `src/index.css`: Global styles, design tokens, and CSS resets.
- `src/App.jsx`: Main application layout.
- `dist/`: Optimized production build output.

## Maintenance Guide
To update content, modify the respective component files in `src/components/`. For design changes, adjust variables in `src/index.css`.
