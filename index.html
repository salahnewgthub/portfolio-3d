02 / Featured case study

Remote AI Task Delegation

A concrete experiment in the larger idea of an AI digital employee: mobile instruction, connected agent, real laptop action.

From a mobile instruction to a real computer action

Human gives a task. The agent carries it to the laptop.

I integrated OpenAI Codex with my laptop so I can send a bounded development or computer task remotely while away from the machine. The demonstrated example is simple by design: create a folder named myownfolder on the laptop Desktop.

Demonstrated workflow
01 / MOBILE

Send the task

A natural-language instruction starts the workflow from a mobile device.

02 / AI AGENT

Interpret and plan

ChatGPT and Codex process the request and determine the appropriate action.

03 / LAPTOP

Execute the action

The connected coding agent performs the approved task in the computer environment.

04 / RESULT

Find the outcome

The requested folder exists on the laptop when I return and verify the result.

Example instruction
"Create a folder named myownfolder on my laptop Desktop."
Observed resultDesktop/myownfolder

What this proves: a bounded remote task can cross from mobile input to a real computer action. What it does not claim: unlimited computer control, full autonomy, or AGI. This is one working experiment in a larger direction.
